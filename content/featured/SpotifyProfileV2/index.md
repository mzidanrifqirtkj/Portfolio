A CMS-based sales application developed for MSMEs, featuring 20 customizable design templates to support various business types. Built with Laravel framework focusing on clean architecture, scalability, and maintainability. Designed with modern, responsive user interfaces using Bootstrap and JavaScript to enhance user engagement and accessibility. Implemented efficient database structure and data integration with MySQL for optimized data storage and fast retrieval, enabling streamlined digital sales operations and content management
